# ПОГРЕБОК 🎧

Личная комната твоего слуха: загружаешь txt-экспорты плейлистов — сайт собирает
мозаику артистов, маски-плейлисты, статистику настроения, роаст, письмо себе,
игры, плеер с 30-сек превью и обложками, редактор обложек с автогенерацией под суть.

Всё считается **в браузере**, файлы никуда не уходят. Чужих плейлистов тут нет:
у каждого зашедшего — своя пустая комната и свои данные.

## Быстрый старт
1. Открой сайт (GitHub Pages этого репозитория).
2. 📥 ТВОЙ АРХИВ → загрузи один или несколько `.txt` (формат `1. Артист - Трек`).
3. Живи: меню слева сверху, эпохи и темы справа сверху (🎨), плеер внизу.

## Телеграм-бот и общая база
Смотри `bot/README.md`: бот принимает txt и mp3 (личный локер), сервер
`pogrebok_server.py` даёт профилям облако, общую базу треков/исполнителей/альбомов
и комментарии. Сайту облако подключается ссылкой `?bot=<url>&id=<chat_id>`.

## Приватность
Профили в `data/<chat_id>.json` видны тем, у кого есть ссылка. Не клади сюда того,
что не показал бы другу. `disco.html` (комната автора) в этом репозитории не лежит.
